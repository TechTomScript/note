1. Windows 快捷键

|      快捷键      |          功能           |                             备注                             |
| :--------------: | :---------------------: | :----------------------------------------------------------: |
| **Windows + E**  |      打开资源管理       |        会重新打开一个新的窗口，和之前打开的不同的两个        |
| **Windows + D**  |        显示桌面         | 不管在那个页面，直接返回桌面，如果在桌面按下就会返回上个页面 |
| **Windows + V**  |       打开剪切板        | 默认Ctrl + V会粘贴上次复制的内容，使用这个可以看到之前复制的内容(关机后会清空) |
|   Windows + L    |          锁屏           |          人不在电脑旁边时使用，下次要输入密码才能用          |
| Windows + 方向键 |      软件窗口分屏       | Windows + 上、下、左、右会朝着指定的方向分屏(Windows11可以通过鼠标悬浮右上角第二个窗口最大化案件实现更多的窗口排列) |
| Windows + 数字键 | 打开/切换任务栏上的软件 | Windows + 1打开任务栏上面的第一个软件，Windows + 2打开任务栏上面的第二个软件，以此类推，最多是 Windows + 0 打开第十个软件 |

2. Ctrl 快捷键

|      快捷键      |        功能         |            备注            |
| :--------------: | :-----------------: | :------------------------: |
|  Ctrl + A/X/C/V  | 全选/剪切/复制/粘贴 |                            |
|     Ctrl + N     |  当前软件新开窗口   |     可能部分软件不支持     |
| Ctrl + Shift + N |   快速新建文件夹    |     可能部分软件不支持     |
|     Ctrl + W     |  快速关闭当前软件   | 关闭前注意软件内容是否保存 |
|     Ctrl + Z     |      撤销操作       |                            |
|     Ctrl + Y     |    取消撤销操作     |   可能部分软件逻辑不一样   |

3. Shift 快捷键

|       快捷键       |           功能           |                                                      备注                                                      |
| :----------------: | :----------------------: | :------------------------------------------------------------------------------------------------------------: |
|   Shift + Delete   | 永久删除(不会进入回收站) | 正常Delete是只删除文件到回收站，Shift + Delete是永久删除，一般在外面用别人的电脑用完后可以把自己的文件永久删除 |
|  Ctrl + Shift + T  | 恢复浏览器刚才关闭的窗口 |                                仅浏览器支持，刚才误操作关了一个有用的窗口时使用                                |
| Ctrl + Shift + Esc |      打开任务管理器      |                                 和鼠标在任务栏空白处右键-> 点击任务管理器一样                                  |

4. Alt 快捷键

|          快捷键          |        功能        |                                  备注                                  |
| :----------------------: | :----------------: | :--------------------------------------------------------------------: |
|      **Alt + Tab**       | 切换打开的软件窗口 | 按住Alt键，然后按Tab键(按一次切换一个窗口)，松手打开刚才选择的软件窗口 |
| Alt + Enter/双击鼠标左键 |    查看文件属性    |                   和在文件上右键->选择属性的功能一样                   |
|         Alt + F4         |   关闭窗口/关机    |  在打开窗口时和Ctrl + W的功能一样，但是当没有窗口时，按Alt + F4会关机  |
